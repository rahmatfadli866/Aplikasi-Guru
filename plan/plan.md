# Rencana: Menjalankan Aplikasi "Sistem Manajemen Nilai Siswa"

## Konteks
Kode aplikasi sudah ada dan lengkap. Ini adalah aplikasi mobile (Expo) untuk
guru mengelola data siswa, nilai, kehadiran, dan profil guru. Permintaan Anda
adalah menjalankan aplikasi tersebut — bukan menambah fitur baru.

Fitur yang sudah ada di dalam kode:
- Beranda dengan ringkasan (jumlah siswa, kelas aktif, dsb.)
- Input nilai siswa per kategori (Bab 1–10, Quiz, UTS, US)
- Rekap nilai
- Kehadiran siswa (hadir / sakit / izin / alpa)
- Data master siswa & kategori
- Profil guru dengan foto
- Ekspor (cetak/berbagi) dari data

## Yang Akan Dilakukan
1. Memastikan layanan backend dan frontend hidup dan sehat.
2. Menjalankan pemeriksaan cepat bahwa aplikasi terbuka tanpa error dan data
   dasar (kategori default) muncul.
3. Memperbaiki error saat startup jika ada (mis. dependensi hilang, layanan
   gagal jalan) agar aplikasi bisa dibuka.
4. Memberi Anda tautan/QR untuk membuka aplikasi di perangkat lewat Expo Go.

## Yang TIDAK Dilakukan
- Tidak menambah fitur baru.
- Tidak mengubah desain atau alur yang sudah ada.
- Tidak mengubah data yang sudah tersimpan.

## Catatan
- Jika saat dijalankan ternyata ada bagian yang error atau tidak berfungsi,
  saya akan laporkan dan perbaiki agar aplikasi bisa berjalan normal.
- Beri tahu jika sebenarnya Anda ingin mengubah atau menambah sesuatu, bukan
  sekadar menjalankan.
